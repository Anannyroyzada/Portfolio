About Me

I am a Backend & Distributed Systems Engineer specialized in building resilient, low-latency microservices with Java 21, Spring Boot 3, PostgreSQL, and Redis.

My engineering philosophy centers on rigorous distributed systems primitives: eliminating race conditions with atomic Redis Lua scripts, implementing non-blocking asynchronous processing with Java 21 Virtual Threads (Project Loom), ensuring high availability with Resilience4j Circuit Breakers, and proving system guarantees through Testcontainers chaos tests and JMH microbenchmarks.

Core Engineering Domains

  • Distributed Rate Limiting & API Gateways

    Spring Cloud Gateway combined with Redis Lettuce client. Implementing Token Bucket and Sliding Window algorithms with atomic Lua execution, circuit breakers, and sub-millisecond p99 latencies.

  • High-Concurrency Job Queues & Workflows

    PostgreSQL-backed job engines utilizing SELECT ... FOR UPDATE SKIP LOCKED and Redis Streams. Virtual thread worker pools, visibility timeouts, exponential backoff retries, and dead-letter queues.

  • Performance Engineering & Microbenchmarks

    Benchmarking critical hot paths using OpenJDK JMH. Comparing Java 21 Virtual Threads against Platform Thread Pools under high blocking I/O loads, verified with Gatling and k6 load tests.

  • Full-Stack Cloud & Containerization

    Multi-tier hosting architecture pairing React (Vite) on Cloudflare Pages with Spring Boot Docker containers on Render, orchestrated by GitHub Actions CI/CD pipelines and Docker Compose.

Unified Cloud & Hosting Topology Cloudflare Pages + Render
