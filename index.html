Ananny Royzada Backend Engineer · TCS

I'm a backend engineer at Tata Consultancy Services, where I build and maintain Java and Spring Boot services for enterprise workflows. My day-to-day is REST contract design, SQL and JPA persistence, production debugging, and shipping changes with cross-functional QA and business teams.

Outside of work I go deeper than the average tutorial: atomic Redis Lua scripts, PostgreSQL SKIP LOCKED queues, Java 21 virtual threads, and benchmark harnesses that prove a design actually holds.
